# Logos de programas financeiros

Assets locais usados pelo catálogo administrativo. Foram priorizados arquivos publicados pelas próprias marcas: central de marca do Sicredi, sites do Banco do Nordeste, Porto, Banco Mercantil, Banestes e Credicoamo. Livelo e Esfera reutilizam os assets já existentes no projeto; Nubank, PicPay e Revolut usam os vetores mantidos pelo Simple Icons. Nos demais casos, a versão PNG é o ícone publicado pelo domínio oficial. Quando a marca não expôs um arquivo reutilizável, foi mantido um fallback vetorial local para evitar imagem quebrada.

Fontes consultadas em 2026-09-10:

- https://marca.sicredi.com.br/logo/
- https://www.bnb.gov.br/imprensa/imagens-e-documentos
- https://www.banpara.b.br/banpara/publicidade/
- https://blog.bancomercantil.com.br/wp-content/themes/mercantil_blog/images/logo-mercantil.svg
- https://github.com/simple-icons/simple-icons/tree/develop/icons

Os nomes de arquivo são estáveis e fazem parte do contrato de `loyalty_programs.logo_url`.
